# **Weekly Update — April 21**

## **What we built last week and why**

Last week, we worked mainly on collaboration polish and UI improvements. We added and edited notification and invite behavior, added a “My Trip” button and loading states, and continued improving the overall UI. We also fixed smaller errors that came up while testing. This was important because users need to understand where they are in the app and how to get back to their trips quickly.

We also started cleaning up the trip pages so the product feels less like a set of disconnected features. The reason we prioritized UI and navigation was that user testing showed the concept was understandable, but users needed clearer next steps after entering the product. GitHub shows work on notifications/invites, loading, UI additions, and several UI updates around this week.

## **What we’re building this week and why**

This week, we are working on trip management and account-level cleanup: delete functionality, password reset, background image selection, and better handling of local sessions. These are not flashy features, but they make the product safer and more complete for real users.

## **Biggest blocker**

The biggest blocker is consistency across the app. Some flows work, but the same interaction can feel different depending on the page. We need to make the product feel like one connected system.
