**Tripable V1 Core Features**

## **1\. Trip Workspace**

A user can create a trip and have one shared planning space for the group.  
MVP scope:

* Create a trip  
* Add trip name, destination, and dates if known  
* View the trip dashboard  
* Keep all planning sections connected to that trip

## **2\. Group Member Invites**

A user can invite friends into the trip so everyone can contribute.  
MVP scope:

* Invite people by email or share link  
* Show who is in the trip  
* Allow invited users to join the shared workspace  
* Basic member list

## **3\. Availability Poll**

Group members can enter when they are available, and the group can see which dates work best.  
MVP scope:

* Add possible date ranges  
* Each member marks availability  
* Show overlap across the group  
* Highlight the best shared dates

## **4\. Destination / Activity Voting**

Group members can suggest and vote on destinations or activities.  
MVP scope:

* Add destination or activity ideas  
* Vote yes / maybe / no  
* Show group preferences

## **5\. Itinerary Builder**

Once the group decides on dates and activities, users can organize the final plan into a simple itinerary.  
MVP scope:

* Add itinerary items  
* Assign day/time  
* Add location or notes  
* Display the plan in order
