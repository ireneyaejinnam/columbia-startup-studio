# Weekly Update — 2026-05-05

**Team:** Standard Deviants
**Product:** HAUNT — social events app for NYC

## What we built last week and why

Onboarding rework: cut the empty-feed problem by adding a 3-event "starter set" (curated NYC events for the next 7 days) so the first screen after signup has something to interact with instead of a blank state. Also added a "your first 3 friends are already here" prompt that surfaces any contacts already on the platform via phone/email match. Both changes were direct responses to the user testing in `20260402/user_testing.md` — people who didn't see anything to do in the first 60 seconds bounced.

On the demand-gen side, we ran the second Reddit Ads creative cycle (the social-layer-led version beat the problem-led version on CTR by a meaningful margin), and tightened the pitch deck based on in-class feedback from the April 28 draft review. Submitted the analytics snapshot.
