# Roam – MVP Features

1. **Activity cards (2×2 grid)** — pulled from Google Maps API based on current location
2. **Time estimates per activity** — travel time + activity duration + 10% buffer
3. **"In a rush today?" toggle** — filters to activities under 60 minutes total
4. **Activity detail + "Go Now"** — deep-links to Apple Maps or Google Maps for directions
5. **Post-activity rating prompt** — push notification after estimated end time to rate the spot
